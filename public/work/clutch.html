01Overview

Medal is social. NVIDIA’s recorder is light. Clutch sets out to be both.

It sits in the tray running an always-on replay buffer. Press the hotkey and it keeps the last few seconds plus a few after, and you can change that length mid-game. Or press nothing: it can clip when you and your friends suddenly get loud, keep every stretch of conversation, or, with an optional AI step, watch for whatever you describe in plain English, like “my kills and goals, never menus”.

Around that sits everything that makes clips worth keeping: a library with hover previews, search and tags, a viewer with trim handles, a 9:16 / 1:1 / 16:9 editor for Shorts and TikTok, Discord posting through a webhook, and YouTube uploads now or on a schedule.

Everything that runs on your PC is free, with no limits. An optional account adds cloud share links and storage, and an optional Pro tier pays for that cloud. Sponsored cards can be switched off in one place and never appear in game.

02Features

What it does.

01

Replay buffer and hotkeys

Save the seconds before and after with one key. Alt+PageUp / PageDown change the length in game, and extra hotkeys can have their own lengths.

02

Clips that make themselves

Hype moments and conversation triggers, both with no AI. Game detection starts recording on launch and tags each clip with the game’s icon.

03

Bring your old library

Medal, OBS, NVIDIA or any folder shows up next to Clutch’s own clips, read where it already is. Nothing is copied, moved or deleted.

04

An editor for vertical video

Crops to 9:16, 1:1 or 16:9 with speed, volume, captions and joining clips, plus a viewer with drag-to-scrub and trim handles.

05

Sharing built in

Discord posting with automatically shrunk copies that play inline, YouTube uploads now or scheduled, and share links anyone can open.

06

Audio like OBS, made simple

Several mics or virtual cables plus game audio, each with its own volume, and optional separate tracks in every clip.

03Engineering

The decisions that matter.

A recorder has one job it must never fail at: stay out of the way of the game. Most of the interesting work follows from that.

Track 1 is always the mix; separate tracks follow it and are named in the MP4. The optional AI step reads small frames from finished segments in a separate process.

01

Capture on the GPU, save without re-encoding

Frames go from screen to encoder without leaving the GPU. Screen, microphones, system audio and a single app’s audio all go into one FFmpeg process that writes two-second MPEG-TS segments into a ring buffer.

Saving a clip stitches the segments it needs by stream copy, so a save is instant and costs nothing extra while you play. On screens wider than 4096 px, Clutch picks HEVC or AV1 automatically.

02

Background work never competes with the game

Exports, Discord copies, thumbnails, text reading and game detection all run below normal priority. Only the live recording stays at normal, so it never drops frames.

The same rule covers updates: Clutch updates itself from GitHub releases, and it never restarts in the middle of a game.

03

AI is optional, and asked only when something happens

For “watch the screen” you describe what to clip in plain English. Clutch watches locally for big changes on screen and loud moments, and only then asks the model whether the moment matches your rules. Calm stretches cost nothing.

It runs on your own Anthropic API key or a Clutch account, and nothing is sent while the feature is off.

04

Import nothing, read everything

People switching from Medal have years of clips. Instead of a migration, Clutch reads existing libraries in place and shows them in the same library, with nothing copied, moved or deleted.

It can also import settings from Medal or OBS, so switching takes minutes.

05

Private by default

Clips are recorded and stored on your PC. Clutch talks to the network only for features you turn on: Discord, YouTube, share links, AI, and update checks against the GitHub repository. There is no telemetry.

The optional cloud server is small, has almost no dependencies, and can be self-hosted from Settings.
