Forest Quest ’88

01Overview

The forest has one rule.

Do anything, and it rearranges itself around you.

Home is in there somewhere. Every turn offers five actions, from weird and funny to normal, boring and outright negative; pick one with a click or a number key, or type your own. The journey is randomised, items drop into your inventory, a map and a journey log keep track, and there are three save slots with autosave.

The comedy is dry on purpose. It works because the game is confident, consistent and completely unhelpful, which turned out to be an engineering constraint as much as a writing one.

02Engineering

Funny is not a model’s job.

The prototype and the shipped game are very different programs, and the difference is the most useful thing this project taught me.

01

Models understand; authored content performs

The prototype used a small embedding model, MiniLM through Transformers.js, only to understand what the player typed, by matching it to the nearest option. An optional local narrator ran through Ollama.

The rule I settled on: understanding the player is a model’s job, but being funny is not. A generative model tries to be coherent and helpful, which is exactly what kills the joke.

02

Ship the story, not the model

For release, the story was baked into a fixed graph: 372 nodes, 95 endings, 11 cryptids and 8 enemies, with no AI at runtime. Players install nothing extra, it runs fully offline, and every run reads the way it was meant to.

The pixel viewport is pure JavaScript, so the whole game works the same everywhere.

03

A web game that ships like a desktop game

The game is Vite and vanilla JavaScript inside a Tauri shell. Pushing a version tag makes GitHub Actions build installers for Windows, macOS and Linux, plus the three raw archives that go to Steam’s depots. No Rust toolchain is needed on the development machine.

04

Achievements that survive being offline

Unlocks are saved locally first, then forwarded to Steamworks through a Tauri command backed by the steamworks Rust crate, compiled in only behind a cargo feature.

On every launch the game re-sends every achievement it has earned. Steam ignores repeats, so nothing is lost if Steam wasn’t reachable the first time, and without Steam both commands are harmless no-ops.
