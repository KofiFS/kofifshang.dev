01The short version

The short version

For ten years I’ve built backend services, data pipelines and platform software that real organisations run on.

All of it on contract, across very different domains: security access control, payment processing, energy analytics, real-time spatial systems, and federal statistical work as a subcontractor to the U.S. Census Bureau. Different stacks and different stakes, but the same job each time: understand the system, change it safely, and leave it easier to run.

Shangko Co is my studio, and it’s where that discipline goes into work with my own name on it. I’ve shipped games on Steam since 2020, nine of them now, as developer and publisher. In October 2026 I released Clutch, an open-source clip recorder for Windows, and two more games. Juicicora, a co-op adventure in Unreal Engine, is the biggest thing I’ve taken on.

I hold an M.S. in Software Engineering from Penn State. I’m based in Pennsylvania and work remotely.

04How I build

Four habits that show up in everything.

Ship, then keep shipping.

Clutch went from first public release to v0.1.8 in under two weeks. Every update installs itself, and it never restarts in the middle of a game.

Measure, don’t guess.

Clutch ships a benchmark script that totals CPU, memory and encoder load across every process it runs, so its performance claims come with numbers anyone can reproduce.

Local first, honest about the cloud.

Clutch records and stores on your PC with no telemetry, and Forest Quest ’88 runs with no AI at all. Anything that touches the network is opt-in and says so.

Tooling is part of the product.

I Can’t See You generates its input mappings, Blueprints and test map from an idempotent Python script, so a fresh checkout rebuilds the same project every time. See how.
